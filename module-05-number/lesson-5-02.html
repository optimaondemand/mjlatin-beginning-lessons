📖 TODAY'S FOCUS
Can one ending tell you the job and the number at the same time?
Yesterday you made subjects plural (-ae). Today you learn the plural object ending and snap all four forms together into one pattern you'll use for the rest of the year.
🎵 MEMORY WORK
Your target is the complete four-cell paradigm for puella (girl). Chant it aloud — singular row first, then plural:
SingularPlural
Nominative (subject)puellapuellae
Accusative (object)puellampuellās
Say each cell as case — number — ending — form: “nominative singular, -a, puella… nominative plural, -ae, puellae… accusative singular, -am, puellam… accusative plural, -ās, puellās.” Then say it backwards.
🎯 BY THE END OF THIS LESSON YOU WILL BE ABLE TO…
1
I will be able to make a 1st-declension object plural by changing -am to -ās.
2
I will be able to recite the full four-cell paradigm from memory.
3
I will be able to name a noun's case and number by reading its ending.
📚 PART 1 · THE PLURAL OBJECT

The object ending goes from -am to -ās

The accusative (object) singular ends in -am. To make the object plural, change it to -ās.

puellam
one girl — the object
puellās
the girls — the object

The little line over the ā in -ās is a macron. It means you hold the vowel a beat longer — and it helps you tell this ending apart from others. Always write it.

📚 PART 2 · THE WHOLE PATTERN

Here are all four forms in one grid. Two questions — what job? (the row) and how many? (the column) — are answered by a single ending:

Singular (one)Plural (many)
Nominative — subjectpuellapuellae
Accusative — objectpuellampuellās
💡 This is a paradigm — a pattern. Learn it once for puella, and it works for every 1st-declension noun you know: porta, via, insula, fossa, copia…
